# Configuration examples

This directory contains reference copies of configuration files, Apache site definitions, systemd units, and supporting scripts used when building and operating the Bitcoin node.

These files are not loaded directly by the dashboard and are not necessarily exact copies of the active files installed elsewhere on the system. Review paths, usernames, ports, credentials, permissions, and version-specific settings before using them.

The files are kept in this repository because the dashboard is installed locally on the node, making them readily available during installation, troubleshooting, and maintenance. The broader workshop website contains the explanatory build instructions.
